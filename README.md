# Лабораторные работы по серверной веб-разработке

В проекте собраны отдельные папки `lab1`-`lab10` под запуск в `XAMPP`.

## Что сделано

### `lab1`
- Создана веб-страница с динамическим контентом на PHP.
- В шапке размещён логотип МосПолитеха и название работы.
- Внизу страницы добавлен текст `задание для самостоятельной работы`.

### `lab2`
- Собран сайт из двух страниц в одном `index.php`.
- На первой странице сделана форма обратной связи с отправкой на `https://httpbin.org/post`.
- На второй странице выводится результат `get_headers()` в `textarea`.

### `lab3`
- Реализована программа решения уравнения `27 - x = 17`.
- Приложение определяет оператор, положение неизвестной переменной и вычисляет `x`.
- Добавлена блок-схема алгоритма в виде `SVG`.

### `lab4`
- Сделан обычный калькулятор с интерфейсом на HTML/CSS/JS.
- Ввод в поле формируется кнопками через JavaScript.
- Выражение отправляется на сервер POST-запросом.
- Результат возвращается через GET-параметр.
- Разбор выражения и вычисление реализованы пользовательскими рекурсивными функциями.

### `lab5`
- Сделана записная книжка с модулями `index.php`, `menu.php`, `viewer.php`, `add.php`, `edit.php`, `delete.php`.
- Все действия выполняются через `index.php`.
- Реализованы просмотр, сортировка, пагинация, добавление, редактирование и удаление записей.
- Для хранения данных используется локальная `SQLite` база `contacts.sqlite`.
- Форма и стиль адаптированы по вашим файлам `form.php` и `style.css`.

### `lab6`
- Сделаны 4 отдельных PHP-файла по ООП:
- `encapsulation.php` — инкапсуляция и приватное свойство цвета кошки.
- `abstract_classes.php` — абстрактный класс `HumanAbstract` и наследники.
- `inheritance.php` — класс `PaidLesson`, наследующий `Lesson`.
- `interfaces.php` — работа с интерфейсом `CalculateSquare` и `get_class()`.

### `lab7`
- Добавлен экшн `sayBye(string $name)`.
- Добавлен маршрут `/bye/name`.

### `lab8`
- `title` передаётся в шаблон через переменную.
- Если `title` не передан, используется `Мой блог`.
- Для `/hello/username` выставляется `Страница приветствия`.

### `lab9`
- После загрузки статьи дополнительно запрашивается автор из таблицы `users`.
- В шаблоне статьи выводится `nickname` автора.

### `lab10`
- Создано представление редактирования статьи.
- Добавлен маршрут `article/{id}/edit`.
- Реализовано сохранение изменений статьи.
