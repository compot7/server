# Лабораторная работа 7

Что реализовано:

- экшн `sayBye(string $name)` в `MainController`;
- маршрут `/bye/name`;
- страница приветствия `/hello/name`;
- шаблон интерфейса в `templates/main.php`;
- стили в `public/style.css`.

## Запуск в XAMPP

1. Скопируйте папку `lab7` в `C:\xampp\htdocs\lab7`.
2. Запустите `Apache` и `MySQL` в `XAMPP`.
3. Импортируйте `database/init.sql`.
4. Откройте:
   - `http://localhost/lab7/`
   - `http://localhost/lab7/hello/student`
   - `http://localhost/lab7/bye/student`
